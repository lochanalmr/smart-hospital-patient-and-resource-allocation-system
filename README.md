# Smart Hospital Patient & Resource Allocation System

Smart Hospital Patient & Resource Allocation System project, made for CSC 1012.

## Functions

1. Register a patient
2. View the bill for a given patient
3. View sorted patient list (lists all registered patients sorted by triage priority and registration order)
4. View report and analytics (shows patient counts by urgency level, total revenue and discounts, ward bed occupancy percentages, and the highest-paying patient)

## Compiling
For compiling using the command-line:
```bash
gcc *.c -o hospital_system
```
An executable will be created, with different file extensions, according to the operating system.
